Zero Ads · Zero Personal Data Tracking

Raazi active installation telemetry transmits only an anonymous locally-stored random UUID, the Raazi app version, and Android SDK level. It contains no personal information, no listening history, and no device identifiers (IMEI/Serial). Full source code is open under the GPL-3.0 license.
